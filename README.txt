REEL.AI — local AI video generator
1. Install Node.js 18 or newer (nodejs.org).
2. Open a terminal in this folder and run:   node server.js
3. Open http://localhost:3000 in Chrome or Edge.
4. Click "API keys", add one or more free keys (Gemini / OpenRouter), then generate.
Keys are saved in keys.json on your computer only. The server listens on 127.0.0.1 (this machine only).
